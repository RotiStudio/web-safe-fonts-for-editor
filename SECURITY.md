# Security policy

## Supported versions

Only the latest release of Web-Safe Fonts for Editor receives security fixes.

## Reporting a vulnerability

Please do not report security issues in public issues or on the WordPress.org support forum.

Report them privately on GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.
If you cannot use GitHub, use the form at [rotistudio.com/contact](https://rotistudio.com/contact/) or write to
[hello@rotistudio.com](mailto:hello@rotistudio.com).

Please include the plugin, WordPress and PHP versions, the steps to reproduce and the impact you expect. We aim to reply
within a few working days and keep you updated until the fix is released. Reporters are credited in the
changelog unless they ask us not to.
